# Топ-даун гонки «Машина едет сама»

Простая 2D-гонка с видом сверху: машина едет вперёд автоматически, игрок рулит **мышью**
и объезжает препятствия, попутный транспорт и собирает бонусы.

Сцена: `Assets/Scenes/Racing.unity` (добавлена первой в Build Settings).

## Управление

| Действие | Клавиши |
|---|---|
| Руление | движение мыши (машина тянется к курсору) / A,D / ←,→ |
| Нитро (ускорение) | ЛКМ / Shift |
| Тормоз | ПКМ / S |
| Старт | кнопка «ПОЕХАЛИ!», **любой клик** или Enter/Space |
| Пауза | кнопка «II» или Esc |
| Рестарт | кнопка «ЗАНОВО», R или клик (через 0.6 с после проигрыша) |

> Клик в любом месте работает как запасной вариант — если мышь по какой-то причине
> не попала точно в кнопку, игра всё равно начнётся.

> В редакторе машина **не реагирует на мышь, если окно Unity не в фокусе** — курсор над
> редактором не должен дёргать машину в сторону. В сборке (билде) это ограничение
> автоматически отключается.

## Правила

* **Скорость** растёт с 9 до 19 м/с, на нитро ×1.45.
* **Здоровье** — 3 сердечка. Столкновение с камнем/бочкой/бордюром/машиной = −1 сердце,
  конус только сбивает скорость. После удара есть 1.6 с неуязвимости (машина мигает).
  При ударе препятствие отлетает и разлетаются искры, камера вздрагивает, машина
  на 0.9 с теряет скорость.
* **Бонусы**: монетка (+100 очков, иногда цепочкой из 3–4 штук), синяя банка (+45 % нитро),
  сердце (+1 здоровье), фиолетовый щит (6 с неуязвимости).
* **Near miss** — проезд вплотную к препятствию даёт +50 очков и комбо ×N (комбо сбрасывается
  через 3 с или при ударе).
* Съезд с асфальта = грунт: скорость падает вдвое, летят пылинки. За пределы обочины
  машина не уезжает (лимит `offRoadLimit`).
* Рекорд сохраняется в `PlayerPrefs`.

## Структура проекта

```
Assets/
├── Art/
│   ├── Cars/        — машины (Kenney Racing Pack, CC0)
│   ├── Objects/     — конусы, бочки, камни, бордюры, деревья (CC0)
│   ├── Generated/   — асфальт, трава, монетка, нитро, щит, сердце, пыль (сгенерировано)
│   └── UI/          — шрифт Inter
├── Scripts/
│   ├── GameManager.cs     — состояние игры, скорость, очки, здоровье, рекорд
│   ├── CarController.cs   — физика машины, руление мышью, нитро, урон, грунт
│   ├── CameraFollow.cs    — камера с упреждением и тряской
│   ├── ObstacleSpawner.cs — волны препятствий и попутный транспорт
│   ├── Obstacle.cs        — конус/твёрдое препятствие + подсчёт near miss
│   ├── TrafficCar.cs      — машины соперников
│   ├── Pickup.cs          — бонусы (монетка/нитро/ремонт/щит)
│   ├── PickupSpawner.cs   — расстановка бонусов по трассе
│   ├── InfiniteGround.cs  — бесконечная трава и дорога
│   ├── DustTrail.cs       — след пыли
│   └── GameUI.cs          — HUD и экраны
└── Editor/
    ├── ArtImportPostprocessor.cs — автонастройка импорта спрайтов (64 px/unit)
    ├── RacingSceneBuilder.cs     — сборка сцены целиком
    └── OpenRacingSceneOnLoad.cs  — открывает сцену гонки при запуске редактора
```

Сцена собирается одной командой: **Tools → Racing → Собрать сцену гонки**
(пересоздаёт всё с нуля, можно крутить параметры в инспекторе и пересобирать).

> В сцене обязательно должен быть объект **EventSystem** с `InputSystemUIInputModule` —
> без него uGUI-кнопки не реагируют на клики вообще. Билдер создаёт его автоматически.

## Сборка игры (Windows)

В редакторе: **Tools → Racing**

| Пункт меню | Что делает | Результат |
|---|---|---|
| Собрать сцену гонки | пересоздаёт сцену с нуля | `Assets/Scenes/Racing.unity` |
| Собрать EXE для Windows | обычная сборка Unity | `Build/Windows/` (папка, 131 МБ) |
| **Собрать один .exe** | сборка + упаковка в один файл | **`Build/TopDownRacing.exe` (40 МБ)** |

Готовый `TopDownRacing.exe` — **один файл**: запускаешь двойным кликом, игра открывается
окном 1280×720. Никакой установки, никаких папок рядом, никаких окон распаковки.
(Он молча распаковывает себя во временную папку — по-другому один .exe в Unity не сделать,
для этого нужен сторонний пакер типа Enigma Virtual Box.)

Игра запускается **в окне** (не во весь экран), окно можно растягивать.
Настройки окна задаются в `RacingSceneBuilder.ConfigurePlayerSettings()`.

> Сборка использует Mono (IL2CPP-модуль в этом Unity не установлен) и требует
> WinRAR с SFX-модулем для упаковки в один файл.
